# growi-plugin-tracker

GROWIのMarkdownに、進捗バー・マイルストーン・カウンターを追加するscriptプラグイン。

## 記法

### 進捗バー

```
::progress[開発]{value=75 max=100 color=#2f6f4f}
```

- `value` / `max`: 現在値・最大値(省略時は `max=100`)
- `color`: バーの色(省略可、省略時はテーマの primary 色)
- `[開発]` の部分がラベルとして表示される

### マイルストーン

```
:::milestone{title="v2.0 リリース"}
- [x] 2026-01-10 要件定義
- [x] 2026-03-01 設計
- [ ] 2026-08-30 リリース
:::
```

中身は通常のGFMタスクリスト。チェック済み/全体の数から達成率を自動計算して表示する。
GROWIのページ上でチェックボックスをクリックすると(GROWI標準のタスクリスト編集機能により)
リアルタイムに達成率が更新される。

### カウンター

```
::counter{id="likes-top-page" value=0 step=1}[いいね]
```

- `id`: ブラウザの `localStorage` に保存するためのキー。同じ `id` を持つカウンターは
  ページを再読み込みしても値が保持される(**サーバー側には保存されない = 閲覧者ごと・
  ブラウザごとの値**である点に注意)。`id` を省略すると保存されない一時カウンターになる。
- `value`: 初期値、`step`: +/- ボタン1回あたりの増減量

## セットアップ

```bash
pnpm install   # または yarn / npm
pnpm build     # dist/ に成果物を生成する。dist/ はビルド後に git commit する
```

GROWIはプラグインをGitHubリポジトリから直接取得し、`dist/manifest.json` を読み込む
(サーバー側でビルドはしない)。そのため **`dist/` はビルド後に必ずコミットしてpush**
すること。

## GROWIへの登録

1. このディレクトリをGitHubリポジトリとしてpush(リポジトリに `growi-plugin` トピックを
   付けておくと一覧に出やすくなる)
2. GROWI管理画面 → プラグイン → 「プラグインインストーラー」に、このリポジトリの
   GitHub URLを入力してインストール
3. インストール後、対象ページで上記の記法を使うと即座に反映される(プレビューにも反映)

## 実装メモ

- GROWIのMarkdownパイプラインには remark-directive が標準で組み込まれているため、
  このプラグイン自身は remark-directive を同梱していない
  (`::name{...}` 構文は既にディレクティブASTノードとしてパース済みの状態で渡ってくる)。
- サニタイズ(`hast-util-sanitize`)はタグ名のホワイトリスト方式で、サードパーティ
  プラグインからは拡張できない。そのため独自タグ名は使わず、既に許可されている
  `figure` / `data` タグ + 常に許可される `data-*` 属性に載せてディレクティブの情報を
  運び、`components.figure` / `components.data` を既存コンポーネントをラップする形で
  上書きしている(`data-gpt-widget` 属性が無い要素はそのまま素通しする)。
